# Python

## 버전 선택

[여기](https://www.python.org/downloads/)에서 필요한 버전을 선택해 다운로드하면 된다.

새 프로젝트를 생성하는 경우 되도록 최신 버전을 추천하지만, 일부 라이브러리가 최신 Python을 지원하지 않을 수 있으니 의존성 확인이 필요하다.
`requirements.txt` 등으로 가상환경을 새로 생성하는 경우, 기존 환경의 파이썬 버전과 다른 파이썬 버전을 사용하면 의존성 문제가 발생할 수 있다.

# conda vs pip

| 항목        | conda    | pip    |
| --------- | -------- | ------ |
| 저장 방식     | 중앙 캐시에 저장  | 환경별로 저장 |
| 디스크 효율    | 높음       | 낮음     |
| 설치 속도     | 빠름 (재사용) | 느림     |

대용량의 라이브러리가 필요한 프로젝트가 아니라면, pip을 사용하는게 유리할 수 있다.
그리고 `PyTorch`같이 `conda install`을 지원하지 않는 경우도 있어서, 그냥 pip을 쓰는게 마음이 편할 수 있다.

# Python 버전 관리

## Install just for me vs Install for all users

* **Install just for me**
  * 현재 사용자 계정만 사용 가능
  * 관리자 권한 불필요
  * 일반적으로 아래와 같은 경로에 설치됨:
    ```bash
    C:\Users\사용자명\AppData\Local\Programs\Python\Python312\
    ```
  * 가장 안전하고 충돌이 적음
  * 개인 개발용으로 추천

* **Install for all users**
  * PC의 모든 사용자 계정에서 사용 가능
  * 관리자 권한 필요
  * 일반적으로 아래와 같은 경로에 설치됨:
    ```bash
    C:\Program Files\Python312\
    ```
  * 여러 계정이 함께 쓰는 PC에서 유용
  * 회사/학교 환경에서 주로 사용

관릭자 권한을 신경쓰기가 귀찮으니 혼자 쓰는 PC에서는 **Install just for me**가 낫겠다.

## 파이썬 버전 폴더(versions) 위치

### Windows

보통:

```bash
C:\Users\사용자명\AppData\Local\Programs\Python\
```

또는

```bash
C:\Program Files\
```

안에 버전별로 폴더가 있다.

```bash
Python310
Python311
Python312
```

아래 명령어를 통해 어떤 경로의 python을 사용중인지 확인할 수 있다.

```bash
# cmd & PowerShell
python -c "import sys; print(sys.executable)"

# PowerShell
Get-Command python
```

또는 아래 명령어를 통해 PATH에 있는 모든 python.exe를 확인할 수 있다.

```bash
# cmd
where python

# PowerShell
Get-Command python -All
```

일반적으로 `python` 명령은 `where`의 첫 번째 결과를 실행한다.

### macOS

공식 설치기 사용 시:

```bash
/Library/Frameworks/Python.framework/Versions/
```

안에 버전별로 폴더가 있다.

```bash
/Library/Frameworks/Python.framework/Versions/3.12/
```

아래 명령어를 통해 어떤 경로의 python을 사용중인지 확인할 수 있다.

```bash
which python3
```

# 가상환경 생성

```bash
python -m venv .venv
```
를 사용하여 현재 위치에 가상환경을 생성할 수 있다. 이때

```bash
which python        # Mac / Linux
```
```bash
where python        # cmd
Get-Command python  # PowerShell
```
를 사용하여 현재 어떤 Python이 실행되고 있는지 확인할 필요가 있다. 또는

```bash
python --version
```
```bash
python -v
```
를 이용해 Python의 버전을 확인할 수도 있다.

`python` 명령어 대신 `python3.11`과 같이 버전을 지정해줄 수도 있다. 이 경우,
```bash
which python3.11
python3.11 --version
```
과 같은 방식으로 해당 버전의 파이썬이 설치되었는지 확인해볼 수 있다.


# 라이브러리 설치

아래 명령어를 통해 가상환경을 활성화할 수 있다.
```bash
source .venv/bin/activate   # Mac / Linux
.venv/Scripts/activate      # Windows (Git Bash)
.venv\Scripts\activate.bat  # Windows (cmd)
.venv\Scripts\Activate.ps1  # Windows (PowerShell)
```

가상환경이 활성화되었다면 CLI에서도 확인할 수 있겠지만, `which python` 등을 통해 활성화된 python이 맞는지 확인해볼 수도 있다.

아래와 같이 패키지를 설치할 수 있다.
```bash
python -m pip install numpy
```

또는 아래와 같이 `requirements.txt`를 사용하여 한번에 설치할 수도 있다. 
```bash
pip install -r requirements.txt
```

만약 현재 설치된 패키지 목록을 내보내고 싶다면
```bash
pip freeze > requirements.txt
```
를 이용할 수 있다.
